# Workspace Rules & Customizations

## Git Push Policy (STRICT - NEVER AUTO PUSH)
- DILARANG melakukan `git push` otomatis ke remote repo kecuali diinstruksikan secara eksplisit oleh user dengan pesan seperti "git push".
- Setiap perubahan kode HANYA disimpan secara lokal. Agen HARUS menunggu perintah "git push" dari user sebelum menjalankan perintah push ke remote repository.
